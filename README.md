# LabLib

LabLib 是本地优先的科研文献管理应用。本仓库用于安装包发布和用户问题反馈，不包含应用源码。

- [下载安装包](https://github.com/langjihao/lablib-releases/releases)
- [反馈问题](https://github.com/langjihao/lablib-releases/issues/new/choose)
- [查看已反馈的问题](https://github.com/langjihao/lablib-releases/issues)

首次内测安装包发布后会出现在 Releases。目前没有可下载的公开版本。

也可以在应用的“设置 → 更新与备份”中检查版本、下载安装包；“设置 → 问题反馈”会预填运行环境。

反馈公开可见。请描述复现步骤、预期结果和实际结果，提供应用版本及操作系统；截图请遮盖个人信息。不要上传数据库、Vault、配置文件、API Key 或完整日志。

更新前请保存当前编辑。应用会备份本地数据后打开安装包，安装步骤由用户完成；备份可在设置中打开，也可复制到其他磁盘。
