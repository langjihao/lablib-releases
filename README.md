# LabLib

本地优先的科研文献库。这个仓库只发布安装包、接收问题反馈，不包含应用源码。

网站：<https://langjihao.github.io/lablib-releases/>

## 下载

公开安装包还没有发布。发布之后会出现在 [Releases](https://github.com/langjihao/lablib-releases/releases)。已经装好的应用也可以从「设置 → 更新与备份」检查。

更新前请先保存正在编辑的内容。应用会备份本地数据，然后打开安装包；安装由你自己完成。备份可以在设置里打开，也可以复制到别的磁盘。
